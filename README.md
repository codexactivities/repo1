# EvalBench

Лаборатория промпт-инженера: версии датасетов и промптов, генерация A/B, программные graders и LLM-as-a-judge, повторные измерения, сравнение с baseline, разбор регрессий и слепая ручная оценка.

**[Открыть приложение](https://evalbench-prompt-lab.dot-punks-gp-9267.chatgpt.site)** · **[Исходный код](evalbench/)** · **[Документация](evalbench/README.md)** · **[Проверки](evalbench/VERIFICATION.md)**

Приложение приватное; сервер и D1 размещены в Sites/Cloudflare. GitHub Pages — ссылка на него. Полный код, миграции, тесты, примеры и CLI доступны в этом репозитории для Claude Code, Codex и других coding agents. Начните с `evalbench/AGENTS.md`.

Ключ провайдера подключается в приложении и шифруется на сервере. Без ключа доступен полноценный синтетический прогон, включая синтетический judge; он явно обозначен и не выдаётся за тест живой модели.
