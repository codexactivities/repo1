# EvalBench 2

Серверная лаборатория для evals: A/B-промпты, наборы тестов, автоматические проверки, регрессии, слепая оценка, сохраняемые прогоны и экспорт.

- [Открыть приватное веб-приложение](https://evalbench-prompt-lab.dot-punks-gp-9267.chatgpt.site)
- [Код, настройка провайдера и запуск](evalbench/README.md)
- [Инструкции для Claude Code и других агентов](evalbench/AGENTS.md)
- [Архитектура](evalbench/ARCHITECTURE.md)
- [Функциональная проверка](evalbench/VERIFICATION.md)

Веб-приложение работает на Worker с D1-базой. GitHub Pages открывает его; серверный код и все остальные исходники доступны здесь, в `evalbench/`.

`web/` — исходники интерфейса и правил; `server/` — API, очередь и провайдер; `worker/` — серверная точка входа; `db/` и `drizzle/` — схема и миграции.

Проходят 21 тест и production build. Синтетический серверный режим работает без ключа. Реальные LLM-вызовы требуют серверного API-ключа, который не хранится в этом репозитории.

Для разработки прочитайте `evalbench/README.md`. Для старого локального режима без облачной базы: `cd evalbench && npm run start:local` (Node >=22.13).
